⚠️ cv_status الحرج

هذا العمود يحدد حالة الحجز والتوفر:

0 = غير محجوز
1 = محجوز
2 = باك آوت
3 = معلق
4 = تم الترحيل
5 = هروب
تحذير: cv_status ≠ status العادي!
هذا عمود خاص بحالات الحجز والتوفر وليس مجرد active/inactive
