## ⚙️ **الخطوات التفصيلية (النظام البسيط):**

### **1️⃣ CVs → Maids:**
```
1. تصدير CVs إلى CSV (2,173 سجل)
2. فحص البيانات والأعمدة
3. تطابق الأعمدة:
   - cvs_name → name
   - national_id → nationality_id  
   - cv_status → available & status
4. نقل تدريجي (100 سجل/دفعة)
5. تحقق: CVs=2,173 ↔ Maids=2,173 ✅
```

### **2️⃣ Contracts:**
```
1. تصدير Contracts إلى CSV (1,916 سجل)  
2. فحص البيانات والعلاقات
3. تطابق الأعمدة حسب البنية الجديدة
4. نقل تدريجي مع ربط العلاقات
5. تحقق من العقود والعملاء
```

### **3️⃣ Requests:**
```
1. تحليل جدول Requests أولاً
2. تحديد البيانات المطلوبة
3. تطابق مع البنية الجديدة
4. نقل حسب الأهمية
```
