📋 قائمة العاملات ➕ إضافة عاملة جديدة
  1. اضغط الرابط أعلاه "إضافة عاملة جديدة" أو اذهب إلى: الاستقدام ← العاملات ← إضافة

من الواجهة

📋 قائمة عقود الإيواء ➕ إضافة عقد إيواء جديد
  1. اضغط "إضافة عقد إيواء جديد" أعلاه
  2. اختر العاملة والعميل (الكفيل القديم) وأدخل بيانات العقد
  3. في حقل "رغبة العمل" اختر نعم — يرغب في النقل ⚠️ ضروري
  4. احفظ — حالة العقد تصبح shelter تلقائياً

⚠️ مشكلة شائعة — العقد لا يظهر في القائمة؟

إذا أنشأت العقد ولم يظهر في dropdown نقل الكفالة، السبب هو أن حقل "رغبة العمل" لم يُختَر كـ "نعم" أثناء الإنشاء.

الحل: اذهب إلى عقد الإيواء ← تعديل ← اختر "رغبة العمل = نعم" ← احفظ. ثم يظهر العقد فوراً.

SQL — للاختبار السريع

⚠️ استخدم هذا للاختبار فقط وليس في الإنتاج
UPDATE contracts SET status = 'shelter' WHERE id = [رقم العقد];
3
تفعيل "رغبة العمل = نعم" — المفتاح الرئيسي

الطريقة 1 — من صفحة تفاصيل عقد الإيواء (موصى بها)

📋 عقود الإيواء ✅ المتاح للنقل
  1. اذهب إلى: الإيواء ← عقود الإيواء واضغط على العقد
  2. ابحث عن قسم "رغبة العمل" في الصفحة
  3. اضغط زر تغيير الرغبة واختر "نعم — يرغب في النقل"
📌 بعد التغيير مباشرة: يظهر زر "بدء نقل الكفالة" في صفحة تفاصيل العقد — اضغطه للانتقال مباشرة لإنشاء طلب النقل.

الطريقة 2 — من "المتاح للنقل"

  1. اذهب إلى: الإيواء ← المتاح للنقل
  2. إذا ظهر العقد اضغط مباشرة "بدء نقل الكفالة"

SQL — للاختبار السريع

-- تحقق أولاً من وجود السجل
SELECT * FROM contract_infos WHERE contract_id = [رقم العقد];

-- إذا وُجد
UPDATE contract_infos SET wants_to_work = 'yes' WHERE contract_id = [رقم العقد];

-- إذا لم يوجد
INSERT INTO contract_infos (contract_id, wants_to_work, created_at, updated_at)
VALUES ([رقم العقد], 'yes', NOW(), NOW());

📋 مصروفات الإيواء ➕ إضافة مصروف إيواء
  1. اضغط "إضافة مصروف إيواء" أعلاه
  2. أدخل المبلغ الإجمالي وعدد العاملات
  3. في التخصيصات — اختر العاملة/العقد وأدخل المبلغ المخصص لها
💡 مثال: مصروف شهري 50,000 ÷ 10 عاملات = 5,000 لكل عاملة. بعد 3 شهور: 15,000 ريال يظهر كتكلفة إيواء في القيد.
