## 📋 **خيارات التنفيذ:**

### **1. 🌐 الواجهة التفاعلية (الأسهل):**

#### **الخطوات:**
1. **افتح:** `http://127.0.0.1:8002/?page=full_migration`
2. **اختر الخيارات:**
   - ✅ إنشاء نسخة احتياطية (مُوصى)
   - ✅ تخطي البيانات الموجودة
   - ✅ التحقق من صحة البيانات
3. **اختر الجداول للنقل:**
   - ✅ البيانات المرجعية (البلدان، المدن)
   - ✅ المستخدمون والعملاء
   - ✅ العاملات والسير الذاتية
   - ✅ الطلبات والعقود
   - ⚠️ المحتوى والإعدادات (اختياري)
4. **انقر "معاينة خطة النقل"** للمراجعة
5. **انقر "بدء النقل الشامل"**
6. **راقب التقدم** في الوقت الفعلي

### **2. ⚡ سطر الأوامر (الأسرع):**

#### **النقل الكامل بأمر واحد:**
```bash
cd /Applications/MAMP/htdocs/ERP_V/migration_system
./run_full_migration.sh full
```

#### **خطوات منفصلة:**
```bash
# فحص قواعد البيانات
./run_full_migration.sh check

# إنشاء نسخة احتياطية
./run_full_migration.sh backup

# تنفيذ النقل
./run_full_migration.sh migrate

# فحص النتائج
./run_full_migration.sh verify
```

## 📊 **ما سيتم إنجازه:**

### **🔧 إضافات البنية:**

#### **جداول جديدة ستُنشأ في Platinum:**
- `about_us` + `about_us_translations` - صفحات معلومات عنا
- `complaints` + `complaint_types` - نظام الشكاوى  
- `deportation_procedures` - إجراءات الترحيل
- `travel_histories` - تاريخ السفر
- `sponsorship_transfers` - نقل الكفالة

#### **حقول جديدة ستُضاف:**

**في جدول `users`:**
- `first_name`, `last_name` - الاسم مقسم
- `national_num` - رقم الهوية
- `phone2` - هاتف إضافي
- `birthdate` - تاريخ الميلاد
- `register_from` - مصدر التسجيل
- `is_blocked`, `status` - حالة الحساب

**في جدول `cvs`:**
- `name` - اسم العاملة
- `nationality_id`, `religion_id` - الجنسية والديانة
- `available`, `is_pinned` - حالة الإتاحة
- `experience_years`, `experience_status` - الخبرة
