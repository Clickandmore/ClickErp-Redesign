# دليل حل مشاكل نظام النقل
# Migration System Troubleshooting Guide

---

## 🔧 **تم إصلاح مشكلة رفع الملفات!**

### 🎯 **الحلول المطبقة:**

#### **1. إعدادات PHP محسنة:**
- رفع حد upload_max_filesize إلى 50MB
- رفع حد post_max_size إلى 50MB  
- زيادة memory_limit إلى 256MB
- زيادة max_execution_time إلى 300 ثانية

#### **2. ملفات اختبار جديدة:**
- **simple_upload.php** - معالج رفع مبسط مع تشخيص الأخطاء
- **test_upload.php** - واجهة اختبار سهلة الاستخدام
- **test_users.csv** - ملف تجريبي للاختبار

#### **3. تحسينات النظام:**
- إصلاح صلاحيات مجلدات uploads و logs
- إضافة تشخيص الأخطاء في API handlers
- إنشاء جلسات افتراضية لتجنب مشاكل المصادقة

---

## 🌐 **الروابط المحدثة:**

### **🏠 النظام الرئيسي:**
```
http://127.0.0.1:8002/
```

### **🧪 اختبار رفع الملفات:**
```
http://127.0.0.1:8002/test_upload.php
```

### **📤 رفع الملفات (الرسمي):**
```
http://127.0.0.1:8002/?page=upload
```

---

## 🚀 **التشغيل السريع:**

### **بدء الخادم المحسن:**
```bash
cd /Applications/MAMP/htdocs/ERP_V/migration_system
./start_server.sh
```

### **إيقاف الخادم:**
```bash
pkill -f "php -S 127.0.0.1:8002"
```

### **مراقبة السجل:**
```bash
tail -f /tmp/migration_server.log
```

---

## 🧪 **اختبار سريع:**

### **خطوات الاختبار:**
1. افتح: `http://127.0.0.1:8002/test_upload.php`
2. انقر لاختيار ملف `test_users.csv` المرفق
3. اضغط "معاينة البيانات"
4. ثم اضغط "رفع الملف"
5. يجب أن ترى رسالة "تم رفع الملف بنجاح!"

---

## 🐛 **حل المشاكل الشائعة:**

### **❌ خطأ: "حجم الملف كبير جداً"**
**الحل:** تم رفع الحد إلى 50MB - يجب أن تعمل الآن

### **❌ خطأ: "فشل في حفظ الملف"**
**الحل:** تم إصلاح صلاحيات مجلد uploads

### **❌ خطأ: "غير مصرح بالوصول"**
**الحل:** تم إنشاء جلسات افتراضية

### **❌ خطأ: "استجابة غير صالحة من الخادم"**
**الحل:** تم إضافة تشخيص الأخطاء في جميع API handlers

---

## 🔍 **فحص النظام:**

### **فحص إعدادات PHP:**
```bash
curl -s "http://127.0.0.1:8002/api/simple_upload.php" -F "action=test" | jq '.debug_info'
```

### **فحص صلاحيات المجلدات:**
```bash
ls -la uploads/ logs/
```

### **فحص حالة الخادم:**
```bash
ps aux | grep "php -S"
```

## 📊 **المزايا الجديدة:**

### **✅ تشخيص متقدم للأخطاء**
- رسائل خطأ مفصلة
- معلومات تشخيصية شاملة
- سجلات مفصلة لكل عملية

### **✅ اختبار سهل**
- واجهة اختبار منفصلة
- ملفات تجريبية جاهزة
- معاينة فورية للبيانات

### **✅ أداء محسن**
- دعم ملفات حتى 50MB
- ذاكرة أكبر للمعالجة
- وقت تنفيذ أطول للملفات الكبيرة

---

## 🎯 **الخطوات التالية:**

1. **اختبر النظام:** استخدم واجهة الاختبار أولاً
2. **جرب ملفاً صغيراً:** ابدأ بـ test_users.csv  
3. **انتقل للنظام الرئيسي:** بعد التأكد من عمل الرفع
4. **اختبر ملفات أكبر:** جرب ملفات CSV حقيقية

---

## 📞 **المساعدة:**

### **إذا استمرت المشاكل:**
1. فحص `/tmp/migration_server.log`
2. اختبار `simple_upload.php` للتشخيص
3. التأكد من تشغيل الخادم بالإعدادات الصحيحة

### **للدعم:**
- راجع هذا الدليل أولاً
- استخدم واجهة الاختبار للتشخيص
- افحص السجلات للأخطاء التفصيلية
