اعرض تفاصيل عقد الاستقدام: $ARGUMENTS

1. إذا كان المدخل رقماً فاستدعِ `get_recruitment_contract` من خادم clickerp مع `contract_number`. إن لم يُوجد فجرّبه كـ `id`.
2. إذا كان اسماً أو جوالاً فاستدعِ `list_recruitment_contracts` مع `query`، ثم:
   - عقد واحد ← اجلب تفاصيله بـ `get_recruitment_contract` و`id`.
   - أكثر من عقد ← اعرض قائمة قصيرة واسأل المستخدم أيها يقصد.
3. اعرض بالعربية: المرحلة، العميل، العاملة وجنسيتها، المسوّق، الفرع، الفاتورة (الإجمالي، الضريبة، مدفوعة أم لا)، الضمان، وآخر الملاحظات.
4. إذا رجعت الأداة "خارج نطاق فرعك" فأخبر المستخدم بذلك ولا تبحث بطرق أخرى.
