اعمل تقريراً عن سجل الأنشطة في ClickERP: $ARGUMENTS

1. حوّل الطلب إلى مدخلات `activity_log`: الفترة (`from`/`to`، افتراضياً آخر 7 أيام)، الموظف (`admin`)، النوع (`subject` مثل Contract أو Maid)، أو العملية (`event`).
2. استدعِ `activity_log` مع `limit` = 30.
3. اعرض بالعربية:
   - الإجمالي، وأكثر 5 موظفين نشاطاً.
   - التوزيع حسب العملية (إضافة/تعديل/حذف/دخول) وحسب القسم ونوع السجل.
   - العمليات اللافتة: كل حذف، وتغيير صلاحيات أو أدوار، والدخول بحساب موظف آخر (impersonated)، مع الوقت والموظف.
4. إذا طلب المستخدم تتبع سجل بعينه فاستدعِ الأداة بـ `subject` و`subject_id` واعرض التعديلات بالترتيب (قديم ← جديد).
5. القيم المكتوب عليها `[مخفي]` حقول سرية؛ لا تحاول استنتاجها.
