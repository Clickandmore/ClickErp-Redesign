#💼 موديول إدارة علاقات العملاء (CRM Module)
🧾 الوصف

موديول إدارة علاقات العملاء (CRM) هو مكون أساسي داخل النظام مسؤول عن:

👥 إدارة العملاء والموردين وجهات الاتصال.

🧩 تتبع الصفقات والفرص البيعية من البداية إلى الإغلاق.

📅 إدارة المهام والاجتماعات والمكالمات.

📈 تحليل الأداء البيعي والتسويقي عبر تقارير دقيقة.

🔔 تنظيم وإدارة التواصل مع العملاء لتقوية العلاقات وتحسين تجربة العميل.

يساعد هذا الموديول على بناء إدارة متكاملة للعلاقات مع العملاء، وتحسين أداء فرق المبيعات والدعم..

---

## ✨ المميزات
-👤 إدارة شاملة للعملاء والموردين مع تفاصيل الاتصال والتصنيفات.

📊 إدارة الصفقات والفرص البيعية خطوة بخطوة حتى الإغلاق.

🗓️ إدارة الأنشطة (مهام – اجتماعات – مكالمات) وربطها بالعملاء.

📈 تقارير ولوحات تحكم تفاعلية لتحليل الأداء ومتابعة المبيعات.

🔄 نظام إشعارات وتذكيرات لمتابعة العملاء بشكل فعّال.

🌐 دعم تعدد اللغات والتخصيص الكامل ليناسب احتياجات المؤسسة..

---

## ⚙️ المتطلبات
- PHP `^8.1`  
- Laravel `^10`  
- Composer  
- MySQL Database

---

## 🚀 خطوات التثبيت

بعد نسخ المشروع أو الموديول داخل مجلد `packages` في مشروع Laravel الخاص بك، اتبع الخطوات التالية:

### 1. إنشاء مجلد `packages` (إذا لم يكن موجودًا)
```bash
mkdir -p packages
```

### 2. نقل مجلد الموديول إلى المسار الصحيح
```bash
mv crm packages
```

---

### 3. تسجيل الـ Service Provider
افتح ملف:
```
config/app.php
```
ثم أضف هذا السطر داخل مصفوفة `providers`:
```php
Nami\Crm\CrmServiceProvider::class,
```

---

### 4. تعديل الـ Autoload في Composer
افتح ملف:
```
composer.json
```
ثم أضف الأسطر التالية تحت `autoload > psr-4`:
```json
"Nami\\Crm\\": "packages/crm/src/"
```

---

### 5. تحديث Autoload
قم بتحديث الـ autoload من Composer بالأمر:
```bash
composer dump-autoload
```

---

### 6. تنفيذ المايجريشن
قم بإنشاء الجداول الخاصة بالموديول:
```bash
php artisan migrate
```

---


## 🧑‍💻 ملاحظات
- تأكد من أن المجلد في المسار التالي:
  ```
  packages/crm
  ```
- يمكنك تعديل إعدادات الموديول أو توسيعه حسب احتياج مشروعك.
- هذا الموديول مصمم ليكون **مرنًا** وقابلًا للتكامل مع باقي وحدات النظام.

## 🧭 ملاحظة مهمة
حتى تتمكن من الوصول إلى صفحات الموديول من لوحة التحكم،
يجب إضافة الكود التالي في **ملف الـ Sidebar** الخاص بالمشروع الأصلي:

```php
@php
    $isCrm = request()->is('crm*');
@endphp
 <li class="{{ $isCrm ? '' : 'collapsed' }}">
        <a class="m-link" data-bs-toggle="collapse" data-bs-target="#crm" href="#">
                 <i class="fa-regular fa-file-lines me-2"></i>
                    <span class="ms-2">{{ helperTrans('crm') }}</span>
                   <span class="arrow fa fa-angle-left ms-auto text-end"></span>
                    </a>
                    <ul class="sub-menu collapse {{ $isCrm ? 'show' : '' }}" id="crm">
                        @include('crm::crm')
                    </ul>
                </li>
```
✍️ بعد توجيهات الاستشاري المهندس أحمد مصطفى
