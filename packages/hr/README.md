# 👔 موديول إدارة الموارد البشرية (HR Module)

## 🧾 الوصف
موديول إدارة الموارد البشرية هو مكون داخل النظام مسؤول عن:

🧑‍💼 إدارة بيانات الموظفين وتحديثها.  
🕒 إدارة الحضور والانصراف والإجازات.  
📅 تنظيم جداول الدوام وجدولة المهام.  
📈 تتبع حالة الموظفين وتحديثاتهم.  
📊 استخراج تقارير دقيقة تساعد في اتخاذ القرارات.

يساعد هذا الموديول على تنظيم الدورة الإدارية داخل المؤسسة ورفع كفاءة إدارة الموارد البشرية.

---

## ✨ المميزات
- 👨‍💻 إدارة شاملة لموظفي المؤسسة (بيانات – وظائف – حالات العمل).  
- 🕒 نظام حضور وانصراف مرن مع دعم تسجيل الحضور اليدوي أو التلقائي.  
- 🌴 إدارة الإجازات بأنواعها مع حالات القبول / الرفض.
- 📊 تقارير تحليلية توضح أداء الموظفين والإحصائيات.  
- 🌐 دعم تعدد اللغات وإمكانية التخصيص.  
- 🔐 صلاحيات مرنة تناسب المؤسسات الصغيرة والمتوسطة والكبيرة.

---

## ⚙️ المتطلبات
- PHP `^8.1`  
- Laravel `^10`  
- Composer  
- MySQL Database

---

## 🚀 خطوات التثبيت

بعد نسخ المشروع أو الموديول داخل مجلد `packages` في مشروع Laravel الخاص بك، اتبع الخطوات التالية:

### 1. إنشاء مجلد packages (إذا لم يكن موجودًا)
```bash
mkdir -p packages
```

### 2. نقل مجلد الموديول إلى المسار الصحيح
```bash
mv hr packages
```

---

### 3. تسجيل الـ Service Provider
افتح ملف:
```
config/app.php
```
ثم أضف هذا السطر داخل مصفوفة `providers`:

```php
Nami\Crm\CrmServiceProvider::class,
```

---

### 4. تعديل الـ Autoload في Composer
افتح ملف:
```
composer.json
```
ثم أضف الأسطر التالية تحت `autoload > psr-4`:
```json
  "Nami\\Hr\\": "packages/hr/src/",
  "Nami\\Hr\\Database\\Seeders\\": "packages/hr/database/seeders/"
```

---

### 5. تحديث Autoload
قم بتحديث الـ autoload من Composer بالأمر:
```bash
composer dump-autoload
```

---

### 6. تنفيذ المايجريشن
قم بإنشاء الجداول الخاصة بالموديول:
```bash
php artisan migrate
```

---

### 7. تشغيل Seeder الخاص بالموديول
قم بتشغيل Seeder الأساسي:
```bash
php artisan db:seed --class="Nami\Hr\Database\Seeders\HrDatabaseSeeder"
```

---

## 🧑‍💻 ملاحظات
- تأكد من أن المجلد في المسار التالي:
  ```
  packages/hr
  ```
- يمكنك تعديل إعدادات الموديول أو توسيعه حسب احتياج مشروعك.
- هذا الموديول مصمم ليكون **مرنًا** وقابلًا للتكامل مع باقي وحدات النظام.

## 📄 الترخيص
هذا المشروع مفتوح المصدر ويمكن استخدامه بحرية في المشاريع التجارية أو الشخصية مع الحفاظ على الإشارة إلى المصدر.

## 🧭 ملاحظة مهمة
حتى تتمكن من الوصول إلى صفحات الموديول من لوحة التحكم،
يجب إضافة الكود التالي في **ملف الـ Sidebar** الخاص بالمشروع الأصلي:

```php
  @php
  $isHr = request()->is('hr*');
  @endphp
  <li class="{{ $isHr ? '' : 'collapsed' }}">
        <a class="m-link" data-bs-toggle="collapse" data-bs-target="#hr" href="#">
                 <i class="fa fa-file-text"></i>
                        <span class="ms-2">{{ helperTrans('hr') }}</span>
                        <span class="arrow fa fa-angle-left ms-auto text-end"></span>
         </a>
  <ul class="sub-menu collapse {{ $isHr ? 'show' : '' }}" id="hr">
                        @include('hr::hr')
  </ul>
  </li>
```
✍️ بعد توجيهات الاستشاري المهندس أحمد مصطفى
