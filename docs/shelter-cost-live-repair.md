# نقل تكلفة المورد إلى الإيواء على اللايف

ارفع الملفات التالية مع إصدار المشروع الحالي الذي يحتوي خدمات ودفتر تكلفة الإيواء:

- `app/Console/Commands/CapitalizeMissingShelterCosts.php`
- `app/Services/ingaz/ShelterDirectEntryCostService.php`
- `app/Services/ingaz/LegacySupplierCostResolver.php`
- `app/Http/Controllers/ingaz/ShelterContractController.php`

لا توجد migration جديدة؛ يعتمد التعديل على جداول وحقول الإيواء الموجودة في الإصدار الحالي. يسجل Laravel الأمر تلقائياً.

الإضافات الجديدة للعقود المكتملة/الوصول/الضمان إلى الإيواء تنقل تكلفة المورد المثبتة تلقائياً داخل معاملة الحفظ نفسها. لا تحتاج تشغيل الأمر لكل عقد جديد. إذا كان قيد المورد مفقوداً أو معكوساً فلن تنشأ تكلفة قابلة للاسترداد؛ وإذا فشلت مطابقة قيد موجود يتم رفض الإضافة برسالة السبب والتراجع عنها. تسجيل مطالبة استرداد الوكيل يبقى إجراءً مستقلاً من صفحة العقد.

الأمر التالي لتصحيح العقود التي أضيفت سابقاً فقط:

إذا كان ربط قيد المورد مفقوداً في عقد مستورد، يطابق النظام رقم طلب عربية ورقم فاتورة المورد القديمة مع بيان القيد وتفاصيله، ثم يربط القيد عند التنفيذ فقط. المطابقة المفقودة أو المتعددة (بما فيها قيود الإلغاء) توقف المعالجة دون كتابة. لا تستخدم قيمة الإرسالية لتخمين التكلفة.

مثال العقد 7544 على اللايف بعد رفع الملفات:

```bash
php artisan finance:capitalize-missing-shelter-costs 7544
php artisan finance:capitalize-missing-shelter-costs 7544 --apply --expected-database=alrafedain_dashboard
```

من مجلد المشروع على السيرفر، اعرض المعاينة:

```bash
php artisan finance:capitalize-missing-shelter-costs 7780 7776
```

المعاينة لا تكتب بيانات. تعرض اسم قاعدة البيانات ونتيجة فحص كل عقد. بعد مراجعة النتائج، استخدم اسم قاعدة اللايف الفعلي مكان `LIVE_DATABASE_NAME`:

```bash
php artisan finance:capitalize-missing-shelter-costs 7780 7776 --apply --expected-database=LIVE_DATABASE_NAME
```

- يستخرج المبلغ وحساب المورد من القيد المرتبط بفاتورة العقد؛ لا يعتمد على أرقام قيود أو حسابات القاعدة المحلية ولا يحسب تكلفة جديدة من مبلغ الإرسالية.
- يستخدم تاريخ دخول الإيواء المسجل. إنشاء القيد يخضع لحماية الفترات المحاسبية المقفلة الموجودة في النظام.
- ينشئ مدين أصل الإيواء ودائن مردودات التكلفة، ويترك قيد المورد الأصلي كما هو. لا ينفذ استرداداً من المكتب.
- يتخطى النقل الذي نفذه الأمر سابقاً. يرفض وجود حركات أخرى للعاملة أو قيد أصل إيواء سابق يحتاج ربطاً، والمورد المعكوس أو القيد غير المتوازن.
- كل عقد في معاملة مستقلة؛ قد ينجح عقد ويرفض آخر. يعرض سبب الرفض ويعيد رمز خروج 1 عند أي فشل. يمكن إعادة الأمر دون تكرار العقود المنقولة.
- يعرض أرقام القيود الجديدة بعد التنفيذ؛ قد تختلف عن أرقام القاعدة المحلية.

بعد التنفيذ افتح صفحة كل عقد وتحقق من كشف الإيواء والمبلغ المتاح للاسترداد.
