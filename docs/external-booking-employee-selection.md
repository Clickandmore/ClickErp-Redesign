# اختيار الموظف في حجز السيرة الذاتية من المواقع الخارجية

الإعداد: **إعدادات الموقع ← إعدادات الطلب في الموقع الخارجي ← اختيار الموظف أثناء حجز السيرة الذاتية من الموقع الخارجي**.

- `external_booking_employee_selection` مفعّل افتراضيًا. غياب العمود أو المفتاح من API يبقي تسلسل المواقع القديم.
- عند التعطيل تختفي حقول اختيار الموظف، ويبقى تأكيد الحجز وحقول العميل وتسجيل الدخول حسب وضع الحجز الحالي. يُحفظ الطلب دون `customer_id` ودون إسناد موظف في `order_details`.
- يعيد API التحقق من الإعداد؛ لا يُعتمد على إخفاء الحقل وحده. تمرر المواقع `booking_channel=external_website` للطلبات المسجلة للحفاظ على سلوك عملاء التطبيق الحاليين.
- إعدادا الحجز المبسط وتسجيل الدخول منفصلان، ولم تتغير حجوزات الساعات أو مسار باقات الإيجار.

## التحديث

بعد نشر تعديل النظام، شغّل الترحيل المحدد:

```shell
php artisan migrate --path=database/migrations/2026_09_28_120000_add_external_booking_employee_selection_to_settings.php
```

انشر تعديلات المواقع العشرة قبل تعطيل الإعداد. يمكن نشرها والإعداد مفعّل دون تغيير الخطوات الحالية. الإعداد لا يعيد توزيع الحجوزات القديمة ولا يزيل الموظفين المرتبطين بها.

## التحقق

اختبارات النظام: `tests/Feature/ExternalBookingEmployeeSelectionTest.php`.

اختبارات كل موقع: `ExternalBookingEmployeeSelectionTest.php` للحفظ و`ExternalBookingEmployeeSelectionViewTest.php` لعرض النموذج، داخل `tests/Feature`.

جميع الاختبارات تستعمل بيانات معزولة أو محاكاة API، ولا تنشئ حجوزات على المواقع الفعلية.
