# استكمال العمليات المالية بعد الوصول

في عقود الاستقدام بحالة `arrival` أو `completed` التي ينقصها فاتورة أو إرسالية أو تكلفة تفويض أو تحويل مساند، يظهر زر
«استكمال العمليات المالية» في الإجراءات وتفاصيل العقد عند امتلاك الصلاحية المستقلة
`rec_contracts_late_finance`.

الصفحة: `/admin/RecruitmentContract/{id}/financial-operations`.
يصدر الموظف الفاتورة أولاً، ثم يسجل الإرسالية وتحويل مساند من الصفحة نفسها. بعد حفظ الفاتورة
يمكن إعادة فتح الرابط لاستكمال الإرسالية أو التحويل. تبقى حالة العقد وتواريخ التشغيل كما هي.

قسم الإرسالية يأخذ المكتب من السيرة المرتبطة بالعقد، ويطلب تاريخ الإرسالية ومحطة الوصول
وتكلفة المكتب بالدولار. لا ينشئ إرسالية ثانية ولا يعدّل إرسالية موجودة، ويرفض التسجيل عند
وجود تكلفة مكتب مثبتة دون إرسالية حتى تُراجع البيانات القديمة. بعد حفظ الإرسالية يستكمل
قيد تكلفة المكتب وفاتورة المورد بتاريخ الإرسالية عند تفعيل القيود، ولا يكرر قيد إيراد الوصول.
فشل المحاسبة يلغي حفظ الإرسالية. يبقى مسار الإرساليات المعتاد للعقود الجارية كما هو.

قسم «تكلفة التفويض» يسجل المبلغ الفعلي بالريال والتاريخ ومرجع الدفع، مع اختيار مصدر
الدفع (البنك أو عهدة موظف أو حساب إنجاز) والحساب التابع له. يستخدم القيمة الافتراضية
من الإعدادات ويقبل تعديلها. يتطلب فاتورة للعقد وتفعيل القيود وحساب تكلفة تفويض نهائيًا
في الإعدادات، وينشئ قيدًا متوازنًا واحدًا مرتبطًا بالفاتورة. يمنع التكرار ويحافظ على حالة
العقد وعزل الفروع؛ يبقى مسار تكلفة التفويض المعتاد مقصورًا على العقود الجارية.

يستخدم المسار منطق إصدار الفواتير وتحويلات مساند الموجود. عند تفعيل القيود التلقائية
يستكمل قيود الوصول بتاريخ الفاتورة وفق إعداد إثبات الإيراد وتكلفة المورد؛ التحذيرات
الناتجة عن نقص بيانات المورد تظهر في الصفحة. فشل إنشاء قيود الوصول يلغي إنشاء الفاتورة
داخل المعاملة نفسها. يتطلب تحويل مساند الفاتورة ويمنع تسجيل التحويل مرتين.

صلاحيات إنشاء الفواتير أو إدارة العقود العامة لا تمنح هذا المسار. الصلاحية الخاصة
تسمح بإنشاء فاتورة وتحويل للعقد المحدد فقط، مع استمرار عزل الفروع. عرض وطباعة الفاتورة
بروابطها المعتادة يتطلب صلاحيات العرض والطباعة المعتادة.

## بعد النشر

```bash
php artisan migrate --path=database/migrations/2026_10_05_160000_add_recruitment_late_finance_permission.php --force
php artisan permissions:prepare-server --role-id=1 --role-name=Administrator --attach-first-admin
php artisan permission:cache-reset
php artisan optimize:clear
```

الصلاحية اختيارية ولا يمنحها أمر تجهيز السيرفر تلقائياً. من `/dash/perms/1` ابحث عن
«استكمال العمليات المالية لعقد الاستقدام بعد الوصول»، فعّلها للدور المطلوب والفرع
المطلوب ثم احفظ. استبدل رقم الدور إن لزم.
