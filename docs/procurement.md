# المشتريات الخدمية والمستلزمات

الوصول: الإدارة المالية ← المشتريات (أسفل القيود) (`/finance/procurement`).

- إنشاء طلب أو فاتورة مباشرة، ببنود حرة دون اشتراط صنف مخزني.
- يدعم أي مورد عام مسجل في `fn_suppliers` دون اشتراط مكتب أو وكيل خارجي.
- اختيار المورد، تاريخ المستند والاستحقاق، مرجع المورد، الفرع، مركز التكلفة وعقد الاستقدام اختيارياً.
- حساب الكمية × السعر، خصم ثابت لكل بند، ثم الضريبة المحددة لكل بند. الحساب النهائي على الخادم، والتقريب إلى هللتين لكل بند.
- الطلب: مسودة ← معتمد ← محول لفاتورة. التحويل مرة واحدة، والفاتورة الناتجة مسودة قابلة للتعديل قبل الترحيل.
- الفاتورة: مسودة ← مرحل. القيد: مدين حسابات البنود بالصافي، مدين حساب ضريبة المشتريات بقيمتها، دائن حساب المورد بالإجمالي.
- السداد الجزئي أو الكامل: قيد مستقل مدين المورد ودائن البنك/الخزينة، يظهر تحت الفاتورة مع المرجع والمتبقي. لا ينشئ سند صرف في جدول السندات.
- يمكن تعديل المسودة أو إلغاؤها. الترحيل يقفل المستند؛ لا يوفر هذا القسم حذف القيود أو مرتجعات أو عكس فواتير مرحلة.
- القيود تخضع للسنة المالية النشطة وإقفال الفترات ومسار اعتماد القيود الموجود. حالة «مرحل» تعني إنشاء القيد؛ حالة اعتماد القيد تظهر منفصلة عند انتظار الاعتماد.
- استخدام الريال السعودي فقط. الضريبة تبدأ بصفر ويحددها المستخدم؛ يلزم حساب فرعي مصنف كضريبة مشتريات عند وجود ضريبة.
- لا يعاد تسجيل تكلفة المكتب الخارجي التي سجلها مسار عقود الاستقدام. ربط العقد هنا توثيقي ولا يعدل تكلفة العقد أو فواتيره الحالية.
- هذه الدورة مستقلة عن مشتريات المخزون القديمة. القيود تدخل دفتر الأستاذ وكشف المورد؛ تقارير الفواتير القديمة المبنية على `fn_purchases` لا تجمع مستندات هذا القسم تلقائياً.

الصلاحيات: `finance_procurement_view`, `finance_procurement_create`, `finance_procurement_edit`, `finance_procurement_approve`, `finance_procurement_pay`. صلاحية `finance_module` تحتفظ بالوصول الشامل وفق سياسة الحزمة القائمة. عزل المستندات والربط بالعقد يستخدم خدمة صلاحيات الفروع الحالية.

ترقية البيئات الأخرى:

