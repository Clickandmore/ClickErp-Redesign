# ربط الفواتير المنقولة بقيودها الأصلية

المعاينة:

```sh
php artisan invoices:link-legacy-constraints
```

التنفيذ على قاعدة البيانات المقصودة:

```sh
php artisan invoices:link-legacy-constraints --apply --expected-database=rafdain_test
```

يبحث الأمر برقم الفاتورة القديم أو البيان الكامل «فاتورة: رقم». يلزم قيد وحيد غير محذوف، مطابق للتاريخ والفرع والإجمالي، ومتوازن، ومدين بالكامل لحساب العميل نفسه. لا يُربط قيد مستخدم لفاتورة أخرى، ولا يُستبدل رابط متعارض. وضع إثبات الإيراد يستند إلى شجرة حسابات القيد الأصلي، وليس إعداد الشركة الحالي.

يحفظ الأمر تقرير JSONL في `storage/app/legacy-invoice-links/` يضم نتيجة كل فاتورة والقيم السابقة للحقول المعدّلة. يمكن إعادة التنفيذ؛ المطابقات المرتبطة لا تُنشئ قيودًا جديدة. القيود غير الموجودة أو الملتبسة أو المختلفة تُترك للمراجعة.

عند محاولة استرداد فاتورة استقدام منقولة بلا رابط، يعيد النظام استخدام القيد الأصلي بعد التحقق نفسه. إذا تعذرت المطابقة، يتوقف برسالة واضحة بدل إنشاء قيد فاتورة إضافي على الالتزامات.
