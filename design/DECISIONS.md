# Click ERP — قرارات التصميم المعتمدة

آخر تحديث: 2026-11-15 · المصدر: شيت المقارنة (v1.3 مقابل الريادة) بعد المراجعة.

## القواعد الثابتة
- **الثيم والشكل:** من التصميم الأساسي في جذر المستودع (المشروع الأساسي) فقط. ملف CSS واحد: `assets/clickerp.bundle.css`.
- **الريادة (`design/modules/riyada`) مرجع وظائف فقط:** ناخد منها الوظيفة والحقول والحالات، ونرسمها بثيمنا. ممنوع ننقل ألوانها أو خطوطها أو CSS بتاعها.
- **شاشة الدخول:** تصميمنا (فورم + صورة الرياض) يفضل، وتتضاف عليه حالات الريادة.
- **مسار التشغيل:** `index.html` → `login.html` → `dashboard.html` (الموظفين) أو `cvs.html` (الوكلاء)، والخروج → `login.html`.
- RTL أساسي، عربي وإنجليزي، بيانات وهمية فقط.

## قرارات محسومة
| القرار | المعتمد |
|---|---|
| المسمّى | **نقل الخدمات** بدل «نقل الكفالة» في كل الشاشات والقوائم والحقول |
| المخزون في المالية | **يتشال:** الأصناف، أرصدة أول المدة، الجرد، وتقرير «حركة بيع الأصناف» |
| تنبيه العقود بدون تذاكر | **بعد 60 يوم** |
| هوية المكتب | لوجو واسم المكتب + «by ClickERP» (Multi-tenant) |
| الحسابات التجريبية في الدخول | تتضاف (للعرض والبروتوتايب فقط) |
| المساعد الذكي | يتضاف: زر في الشريط العلوي + شاشة إعدادات |
| الحضور | شارة «حاضر» ومدة الجلسة في الشريط العلوي + نافذة، **ومعاها** كارت الحضور وزر تسجيل الانصراف في الرئيسية |
| «يحتاج قرارك / يحتاج انتباهك» في الرئيسية | **يتشال من الاتنين** |
| «تقارير تخص دورك» في الرئيسية | يفضل |
| الكوبونات | تتصمم (مفيش تصميم في الاتنين) — بريف من الكود |
| باقي ميزات وشاشات الريادة في الشيت | تتعتمد بثيمنا |
